# 安颐院内照护 · 独立院内版 H5

面向住院长辈家属的独立院内陪护 H5：登录后进入「服务预约」，在我的页面查看预约、账户信息与隐私政策。

## 在线预览

**<https://houxueqing.github.io/anyi-hospital-h5/>**

登录规则：

- 手机号：任意 11 位数字
- 验证码：任意 6 位数字
- 登录页不需要演示账号，直接输入即可

> 登录采用手机号 + 验证码；短信验证码为前端模拟，正式上线需接入真实短信服务。

## 与居家照护 H5 的关系

- 独立链接、独立数据、独立账号状态，不与居家照护 H5 共用入口。
- 延续居家照护 H5 的专业蓝、浅色渐变、玻璃卡片、圆角与线性图标体系。
- 页面只保留两个 Tab：**服务预约 / 我的**。
- 业务上不发卡，统一使用**服务券**；供应商接口里的卡号、卡类型字段由服务券在内部映射。
- 申请表单按易得康服务记录申请接口预留字段：服务券、医院编码/城市、入院疾病、护理对象证件/出生日期/地址、联系人信息。

## 页面与流程

1. **登录注册**：参照齿科预约登录页，手机号 + 验证码，任意 11 位手机号、任意 6 位验证码即可登录。
2. **服务预约**：
   - 服务券：展示服务券名称、券号（脱敏）、类型、有效期、使用人，自动使用，不需要选卡
   - 预约机构与住院信息：医院（含医院编码/城市映射）、服务城市、科室/病区、床号、住院日期、入院疾病、住院号
   - 选择预约项目：24 小时陪护 / 12 小时白班 / 12 小时夜班 / 按次陪护
   - 预约时间：7 天日期滑动选择、到院时间、陪护天数
   - 就诊人信息：姓名、性别、出生日期（自动计算年龄）、证件类型/证件号、手机号、省/市/区/地址、自理能力
   - 补充照护需求：术后照护、翻身叩背、助餐喂食、如厕助洁、夜间看护、陪检陪护、康复协助、压疮护理、管路护理、失智照护
   - 联系人：姓名、手机号、证件类型/证件号（选填）、紧急联系人、补充说明、服务协议
   - 底部提交栏位于 Tabbar 上方，滑动到页面底部时显示
3. **我的**：
   - 预约状态：全部 / 待确认 / 已预约 / 已完成 / 已取消
   - 每条预约卡片展示服务名称、订单号、预约时间、就诊人、医院/科室/床号
   - 操作：查看详情、取消预约、修改预约、重新预约
   - 订单详情：服务券、住院信息、护理对象、服务安排、联系人、订单进度、易得康同步状态
   - 客户信息（联系人/护理对象/地址，编辑后同步进行中预约）
   - 账户信息（姓名、登录手机号、会员编号、账户状态，可修改姓名）
   - 隐私政策
   - 服务热线
   - 退出登录

## 技术说明

- 原生 HTML / CSS / JavaScript，无构建步骤。
- 移动端优先，390px 设计，适配 320–430px；桌面端居中为 430px 画布。
- 登录状态、预约、客户档案、默认服务券保存在 `localStorage`，键名 `anyi-hospital-v1`。
- 演示数据含 1 条已完成院内陪护预约、2 张服务券；提交新预约会新增待确认预约。
- 服务券/客户字段按易得康接口文档设计，服务券在内部映射供应商的 `cardNum`、`cardType`；当前为前端演示数据，「易得康同步」为模拟状态，正式上线需后端完成签名、AES 加密和接口调用。
- 不含支付、价格与费用信息，所有服务均为需求提交后由照护顾问电话确认。
- 本版本为高保真产品原型，登录为前端演示校验，正式上线需接入真实账号体系与订单/服务卡接口。
