## 与居家照护 H5 的关系

- 独立链接、独立数据、独立账号状态，不与居家照护 H5 共用入口。
- 延续居家照护 H5 的专业蓝、浅色渐变、玻璃卡片、圆角与线性图标体系。
- 本版本保留院内照护主线：登录 → 填写需求 → 提交 → 我的订单 / 服务卡与权益 / 客户信息 / 账户信息 / 隐私政策 / 退出登录。
- 申请表单已按易得康服务记录申请接口预留字段：服务卡/产品、医院编码/城市、入院疾病、护理对象证件/出生日期/地址、联系人信息。

## 页面与流程

1. **登录**：手机号 + 验证码，登录后直接进入院内照护需求表单。
2. **填写院内照护需求**：
   - 服务权益：选择易得康服务卡，展示产品、卡类型、卡号（脱敏）、服务期、持卡人
   - 住院信息：医院（含医院编码/城市映射）、服务城市、科室/病区、床号、住院日期、入院疾病、住院号
   - 服务安排：24 小时陪护 / 12 小时白班 / 12 小时夜班 / 按次陪护，开始日期、到院时间、陪护天数
   - 照护对象：姓名、性别、出生日期（自动计算年龄）、证件类型/证件号、手机号、省/市/区/地址、自理能力
   - 照护需求：术后照护、翻身叩背、助餐喂食、如厕助洁、夜间看护、陪检陪护、康复协助、压疮护理、管路护理、失智照护（三列选择卡，勾选图标与文字同排）
   - 联系人：姓名、手机号、证件类型/证件号（选填）、紧急联系人、补充说明、服务协议
   - 底部提交栏仅在滑动到页面底部时显示
3. **提交成功**：展示订单编号、服务权益、医院/床号、入院疾病、服务类型、开始时间、照护对象与联系人。
4. **我的**：
   - 我的订单（全部 / 进行中 / 已完成）
   - 订单详情（服务权益、住院信息、护理对象、服务安排、联系人、订单进度、易得康同步状态）
   - 服务卡与权益（卡列表、默认卡、有效期、权益详情）
   - 客户信息（联系人/护理对象/地址，编辑后同步进行中订单）
   - 账户信息（姓名、登录手机号、会员编号、账户状态，可修改姓名）
   - 隐私政策
   - 服务热线
   - 退出登录
5. **订单**：进行中订单可取消，所有订单可查看详情、联系照护顾问。

## 技术说明

- 原生 HTML / CSS / JavaScript，无构建步骤。
- 移动端优先，390px 设计，适配 320–430px；桌面端居中为 430px 画布。
- 登录状态、订单、客户档案、默认服务卡保存在 `localStorage`，键名 `anyi-hospital-v1`。
- 演示数据含 1 条已完成院内陪护订单、2 张服务卡；提交新需求会新增待接单订单。
- 服务卡/客户字段按易得康接口文档设计，当前为前端演示数据；「易得康同步」为模拟状态，正式上线需后端完成签名、AES 加密和接口调用。
- 不含支付、价格与费用信息，所有服务均为需求提交后由照护顾问电话确认。
- 本版本为高保真产品原型，登录为前端演示校验，正式上线需接入真实账号体系与订单/服务卡接口。
