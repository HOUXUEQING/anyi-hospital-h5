# 安颐院内照护 · 独立院内版 H5

面向住院长辈家属的独立院内陪护 H5：登录后进入「服务预约」，在我的页面查看订单统计、进行中预约、卡券与隐私政策。

## 在线预览

**<https://houxueqing.github.io/anyi-hospital-h5/>**

登录规则：

- 手机号：任意 11 位数字
- 验证码：任意 6 位数字
- 登录页不需要演示账号，直接输入即可

> 登录采用手机号 + 验证码；短信验证码为前端模拟，正式上线需接入真实短信服务。

## 与居家照护 H5 的关系

- 独立链接、独立数据、独立账号状态，不与居家照护 H5 共用入口。
- 延续居家照护 H5 的专业蓝、浅色渐变、玻璃卡片、圆角与线性图标体系。
- 页面只保留两个 Tab：**服务预约 / 我的**。
- 业务上不发卡，统一使用**服务券**；供应商接口里的卡号、卡类型字段由服务券在内部映射。
- 申请表单按易得康服务记录申请接口预留字段：服务券、城市/医院、入院疾病、护理人证件/出生日期、联系人信息。
- 服务券为**单次使用券**，每提交一笔预约消耗 1 张；可用次数等于券包中未使用券的张数。

## 页面与流程

1. **登录注册**：手机号 + 验证码，任意 11 位手机号、任意 6 位验证码即可登录。
2. **服务预约**（从上到下）：
   - 权益额度：展示总次数、已使用、剩余次数；每次预约消耗 1 次，取消预约返还
   - 护理人信息：姓名、性别（女/男）、出生日期（自动计算年龄）、证件类型/证件号
   - 住院信息：城市按省/市联动选择；医院从固定服务清单中模糊搜索选择；科室/病区、入院疾病必填，住院日期选填
   - 期望服务时间：日期 + 时间，不选择服务项目、不选择服务时长
   - 护理员要求：指定性别（女/男），补充说明填写对护理员的其他要求或照护需求
   - 材料收集：上传住院申请单/住院凭证、病历资料、检查报告、床头卡、手环等图片或文件，支持增删改
   - 联系人信息：姓名、手机号
   - 底部提交栏位于 Tabbar 上方，滑动到页面底部时显示
3. **我的**：
   - 顶部用户信息（姓名、掩码手机号）
   - 订单统计看板：全部订单 / 待确认 / 服务中 / 已完成，点击进入「我的订单」列表页
   - 正在进行中的订单
   - 院内照护服务（服务详情）
   - 病历资料（统一查看、编辑、删除已上传材料）
   - 隐私政策、退出登录
   - 服务热线以底部灰色文案展示
4. **我的订单**：全部 / 待确认 / 已预约 / 服务中 / 已完成 / 已取消，支持查看详情、取消预约、修改预约、重新预约；订单详情按状态与进度（可滚动/展开）、护理员（如有，含电话/性别/年龄/拨打/复制）、护理人、住院信息、期望服务时间、护理员要求、联系人、订单信息顺序展示。
5. **院内照护服务**：展示适用人群、申请流程、材料审核清单、服务内容、注意事项。
6. **病历资料**：汇总所有订单上传的材料，支持查看图片/文件、上传时间、编辑名称/类型、删除。

### 多权益与空权益交互

- 有权益次数：服务预约页自动选择 1 次权益，提交后剩余次数减 1。
- 已有进行中订单且还有权益：顶部提示「您有 N 个进行中预约，另有 M 次权益可用」，允许继续预约。
- 权益次数用完：服务预约页展示「暂无可用权益次数」，不再展示表单。
- 取消进行中预约：返还 1 次权益。
- 修改预约：沿用原预约已消耗的权益，不额外扣减。

## 技术说明

- 原生 HTML / CSS / JavaScript，无构建步骤。
- 移动端优先，390px 设计，适配 320–430px；桌面端居中为 430px 画布。
- 登录状态、预约、客户档案、券包状态保存在 `localStorage`，键名 `anyi-hospital-v1`。
- 演示数据含 1 条已完成院内陪护预约、4 张单次服务券（1 张已使用，3 张未使用）；每提交一笔预约消耗 1 张未使用券。
- 服务券/护理人字段按易得康接口文档设计，服务券在内部映射供应商的 `cardNum`、`cardType`；当前为前端演示数据，「易得康同步」为模拟状态，正式上线需后端完成签名、AES 加密和接口调用。
- 不含支付、价格与费用信息，所有服务均为预约提交后由照护顾问审核评估并电话确认。
- 本版本为高保真产品原型，登录为前端演示校验，正式上线需接入真实账号体系与订单/卡券接口。
