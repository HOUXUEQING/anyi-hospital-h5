## 与居家照护 H5 的关系

- 独立链接、独立数据、独立账号状态，不与居家照护 H5 共用入口。
- 延续居家照护 H5 的专业蓝、浅色渐变、玻璃卡片、圆角与线性图标体系。
- 本版本只保留院内照护主线：登录 → 填写需求 → 提交 → 我的订单 / 账户信息 / 隐私政策 / 退出登录。

## 页面与流程

1. **登录**：手机号 + 验证码，登录后直接进入院内照护需求表单。
2. **填写院内照护需求**：
   - 住院信息：医院、科室/病区、床号、住院号
   - 服务安排：24 小时陪护 / 12 小时白班 / 12 小时夜班 / 按次陪护，开始日期、到院时间、陪护天数
   - 照护对象：姓名、性别、年龄、自理能力
   - 照护需求：术后照护、翻身叩背、助餐喂食、如厕助洁、夜间看护、陪检陪护、康复协助、压疮护理、管路护理、失智照护（三列选择卡，勾选图标与文字同排）
   - 联系人、紧急联系人、补充说明、服务协议
   - 底部提交栏仅在滑动到页面底部时显示
3. **提交成功**：展示订单编号、医院/床号、服务类型、开始时间、照护对象与联系人。
4. **我的**：
   - 我的订单（全部 / 进行中 / 已完成）
   - 订单详情（住院信息、服务安排、照护需求、护理员、订单进度、订单信息）
   - 账户信息（姓名、登录手机号、会员编号、账户状态，可修改姓名）
   - 隐私政策
   - 服务热线
   - 退出登录
5. **订单**：进行中订单可取消，所有订单可查看详情、联系照护顾问。

## 本地运行

```bash
cd hospital-h5
python -m http.server 4179 --bind 127.0.0.1
```

打开 <http://127.0.0.1:4179/>。

## 技术说明

- 原生 HTML / CSS / JavaScript，无构建步骤。
- 移动端优先，390px 设计，适配 320–430px；桌面端居中为 430px 画布。
- 登录状态、订单、姓名修改保存在 `localStorage`，键名 `anyi-hospital-v1`。
- 演示数据含 1 条已完成院内陪护订单；提交新需求会新增待接单订单。
- 不含支付、价格与费用信息，所有服务均为需求提交后由照护顾问电话确认。
- 本版本为高保真产品原型，登录为前端演示校验，正式上线需接入真实账号体系与订单服务。
