## 1. 产品边界

- 面向住院患者家属的院内照护预约工具。
- 不包含支付、价格、卡号、有效期、券包。
- 使用额度只展示总次数、已使用、剩余次数。
- 护理员、服务记录由运营/供应商侧维护。
- 当前为前端高保真原型，数据保存在浏览器 localStorage；正式上线接后端。

## 3. 全局规则

### 3.1 使用额度

- 页面只展示：总次数、已使用、剩余次数。
- 不展示卡券、券号、有效期、单次使用、卡类型。
- 每次提交预约消耗 1 次权益。
- 取消待确认/已预约订单返还 1 次权益。
- 修改预约沿用原订单已消耗权益，不重复扣减。
- 额度次数为 0：
  - 不展示预约表单。
  - 展示「暂无可用额度次数」。
  - 提供「查看服务详情」「返回我的」。

### 3.2 时间格式

| 场景 | 格式 |
|---|---|
| 预约时间 / 期望时间 | `YYYY.MM.DD HH:mm` |
| 出生日期 | `YYYY.MM.DD` |
| 进度时间 | `MM-DD HH:mm:ss` |
| 下单/上传时间 | `YYYY-MM-DD HH:mm:ss` |

### 3.3 材料

- 支持图片、PDF、Word、Excel。
- 单文件不超过 5MB。
- 可添加多个文件。
- 可编辑材料名称、材料类型。
- 可删除。
- 材料用于服务评估审核。
- 材料列表展示缩略图/文件图标、名称、类型、大小、上传时间。

### 3.4 城市与医院

- 城市：点击后弹出省市双列滚动选择器，省份与城市联动。
- 医院：只能从固定可服务清单选择。
- 医院选择器支持按名称模糊搜索。
- 切换城市后清空已选医院，必须重新选择。
- 不展示医院编码，不允许手工输入清单外医院。

### 3.5 订单状态

| 系统状态 | 展示状态 | 状态标题 |
|---|---|---|
| pending | 待确认 | 预约待确认 |
| accepted | 已预约 | 预约已确认 |
| serving | 服务中 | 服务进行中 |
| completed | 已完成 | 本次陪护已完成 |
| cancelled | 已取消 | 预约已取消 |

- 获取验证码 / 登录

## 4.2 服务预约

### 页面顺序

1. 标题栏「服务预约」。
2. 头图「院内照护预约」+ 副文案 + 医院图案。
3. 进行中提示。
4. 使用额度。
5. 填写护理人信息。
6. 填写住院信息。
7. 材料收集（住院信息下方）。
8. 期望服务时间。
9. 护理员要求。
10. 填写联系人信息。
11. 协议 + 提交栏。
12. Tabbar。

头图文案：

> 填写信息并提交预约，照护顾问将审核评估后确认服务安排。

### 4.2.1 进行中提示

有进行中订单时：

```text
您有 {N} 个进行中预约，另有 {M} 次权益可用，可继续提交新的预约。
[查看订单]
```

点击「查看订单」进入我的订单-全部。

### 4.2.2 使用额度

```text
使用额度                         剩余 3 次
[5 总次数] [2 已使用] [3 剩余次数]
每次预约使用 1 次额度，取消预约后返还
```

- 提交成功后剩余次数减 1。
- 取消后剩余次数恢复。

### 4.2.3 护理人信息

| 字段 | 必填 | 说明 |
|---|---|---|
| 姓名 | 是 | 不能为空 |
| 性别 | 是 | 女 / 男 |
| 出生日期 | 是 | 自动计算年龄 |
| 证件类型 | 是 | 身份证等 |
| 证件号 | 是 | 身份证 18 位校验 |

文案：填写护理人信息 / 用于服务预约与实名。

### 4.2.4 住院信息

| 字段 | 必填 | 交互 |
|---|---|---|
| 城市 | 是 | 点击弹出省市联动选择器 |
| 就诊医院 | 是 | 点击弹出医院搜索选择器 |
| 科室/病区 | 是 | 下拉 |
| 入院疾病/诊断 | 是 | 文本 |
| 住院日期 | 否 | 日期，最大今天 |

#### 省市选择器

- 标题：选择省市。
- 两列：省份 / 城市。
- 两列均可上下滚动。
- 点击省份，城市列联动刷新。
- 点击城市后选中。
- 底部：取消 / 确定。
- 城市展示：`山东省 淄博市`，直辖市显示 `北京市`。

#### 医院输入搜索

- 就诊医院为文本输入框，点击输入框直接输入文字搜索，不弹独立选择弹层。
- 输入时在输入框下方实时展示匹配的医院清单。
- 只匹配当前城市可服务医院。
- 点击匹配项后回填医院名称。
- 无结果：未找到可服务医院。
- 不允许选择清单外医院。

### 4.2.5 期望服务时间

- 快捷：今天 / 明天 / 后天。
- 日期时间必填，不早于今天。
- 不选服务项目、不选服务时长。

### 4.2.6 护理员要求

替换原「照护需求」。

| 字段 | 控件 | 必填 | 说明 |
|---|---|---|---|
| 指定性别 | 随机分配 / 女 / 男 分段 | 是 | 默认随机分配，顺序在最前 |
| 补充说明 | 多行文本 | 否 | 对护理员的其他要求或照护需求 |

Placeholder：

> 例如：希望护理员有骨科护理经验、夜间需要协助起夜等

### 4.2.7 材料收集

标题：材料收集；右侧显示已上传份数。

说明：

> 请上传住院申请单或其他住院凭证、病历资料、检查报告、床头卡、手环等就医材料，用于顾问评估审核。

支持材料：

- 住院申请单 / 住院凭证
- 病历资料
- 检查报告
- 床头卡
- 手环
- 其他就医材料

交互：

- 点击「上传材料」选择图片或文件，支持多选。
- 自动按文件名识别材料类型，可后续编辑。
- 列表展示缩略图/文件图标、文件名、类型、大小、上传时间。
- 每项支持「编辑」「删除」。
- 编辑弹层：材料名称、材料类型、保存。
- 删除弹层：确认删除。
- 点击缩略图/文件：查看图片或文件信息，支持下载/打开。
- 单文件超过 5MB：Toast「{文件名} 超过 5MB，未上传」。
- 添加成功：Toast「材料已添加」。

上传区文案：

- 上传材料
- 支持图片、PDF、Word，单文件不超过 5MB

### 4.2.8 联系人信息

- 姓名必填。
- 手机号必填，11 位。
- 用于顾问确认。

### 4.2.9 协议与提交

协议：

> 我已阅读并同意《院内照护服务协议》与《隐私政策》，确认住院信息与护理员要求真实有效

服务说明：

> 服务由持证护理员提供，到院签到、护理记录全程可追溯

底部：

> 提交后照护顾问将审核评估
> 确认服务安排后与您联系
> [提交预约]

提交成功：

- 消耗 1 次权益。
- 生成待确认订单。
- 进入订单详情。
- Toast「服务申请已提交，照护顾问将评估安排」。

修改预约：

- 标题「修改预约」。
- 沿用原权益，不重复扣减。
- 保存后回到待确认。
- Toast「服务申请已修改，等待评估确认」。

3. 护理员信息（如有）。

- 联系照护顾问。

### 状态与进度

- 状态标签 + 状态标题。
- 时间轴最新在上，时间精确到秒。
- 超过 2 条可滚动，显示「展开全部 / 收起」。

时间轴文案：

| 顺序 | 标题 | 描述 |
|---|---|---|
| 最新 | 服务完成 | 照护结束，服务完成 |
| ↑ | 服务开始 | 护理员已到院签到，照护开始 |
| ↑ | 服务评估完成，已安排护理员 | {护理员姓名} · {护理员等级} |
| 最早 | 服务申请已提交 | 照护顾问已收到院内照护需求，待评估后安排 |

示例：

- 服务完成 / 照护结束，服务完成 / 10-25 08:10:00
- 服务开始 / 护理员已到院签到，照护开始 / 10-18 08:02:00
- 服务评估完成，已安排护理员 / 王秀兰 · 高级养老护理员 / 10-15 17:05:00
- 服务申请已提交 / 照护顾问已收到院内照护需求，待评估后安排 / 10-15 16:28:00

## 4.6 院内照护服务

入口：服务预约页「院内照护预约」标题右侧「服务详情」。我的页面不再提供该入口。

模块：

1. 适用人群。
2. 申请流程：提交预约 → 材料审核 → 顾问评估 → 安排护理员 → 到院服务。
3. 材料审核：住院申请单/住院凭证、病历资料、检查报告、床头卡/手环、其他就医材料。
4. 服务内容（5 大类 14 项，页面内展开显示详细子项）：
   - 一、基本生活照护：饮食照护、排泄照护、生活技能照护、休憩照护
   - 二、清洁与卫生：个人卫生照护、环境卫生照护、物品清洁、用具清洁
   - 三、情况观察：生命体征观察、一般情况观察
   - 四、专项照护：用药照护、舒适照护、安全照护
   - 五、关怀与陪同：心理关怀
5. 注意事项：如实填写、以顾问确认为准、取消修改、贵重物品、病情变化联系医护。
6. 底部「去预约院内照护」。

口吻：面向普通客户，不使用合同术语。

交互：

- 编辑：修改名称、类型。
- 删除：二次确认，删除后同步从订单材料中移除。

## 6. 验收标准

1. 预约页不出现卡券、券号、有效期，只显示权益总次数/已使用/剩余次数。
2. 提交预约后剩余次数减 1；取消后返还。
3. 我的页面无卡券、无院内照护服务入口，有病历资料入口；服务详情入口在「院内照护预约」标题右侧。
4. 城市点击打开省市双列滚动选择器，省份切换城市联动。
5. 医院只能从固定清单模糊搜索选择。
6. 护理员要求为指定性别（随机分配/女/男，默认随机分配）+ 补充说明，无照护需求标签。
7. 材料收集位于住院信息下方，支持图片/文件上传、查看、编辑名称/类型、删除，列表显示上传时间。
8. 病历资料页汇总所有订单材料，支持查看、编辑、删除。
9. 服务详情页包含适用人群、申请流程、材料审核、服务内容、注意事项；服务内容按 5 大类 14 项展示详细子项。
10. 订单详情不展示服务券；展示护理员要求、订单信息和额度消耗。
11. 订单进度文案与服务完成/服务开始/服务评估完成/服务申请已提交一致。
12. 390 和 430 宽度无横向溢出，无 JS 报错。
